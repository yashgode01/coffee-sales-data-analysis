# Coffee Sales Data Analysis

## About the Project

A Python based data analysis project focused on analyzing coffee sales data to identify sales trends, product performance, key KPI's and business insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- KPI Calculation
- Sales & Revenue Analysis
- Product Performance Analysis
- Data Visualization
- Business Insights & Recommendations

## Key KPIs

- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value
- Top-Selling Products
- Sales Trends

## Project Files

- `Coffee_Sales_Analysis.ipynb` – Python analysis notebook
- `coffee_sales.csv` – Dataset
- `images/` – Analysis visualizations

## 💡 Key Outcome

The project converts raw coffee sales data into meaningful visualizations and actionable business insights to support sales and product decisions.
